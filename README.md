# 🌍 Multilingual Learning Material Summarizer

Автоматическое абстрактивное резюмирование учебных материалов на **английском, русском и немецком языках**.

---

## 📖 Описание

**Что делает проект?**  
Инструмент принимает текстовый файл или PDF с лекцией, статьёй или учебным пособием и генерирует краткое, связное резюме, сохраняя ключевые идеи.

**Зачем это нужно?**  
Студенты и исследователи часто сталкиваются с большими объёмами информации на разных языках. Этот инструмент экономит время, автоматически выделяя суть без потери контекста — особенно полезно при подготовке к экзаменам или обзоре литературы.

---

## 🛠️ Требования

- **Python 3.8–3.12**
- `pip`
- Доступ в интернет (для первой загрузки модели)

## 🚀 Установка

```bash
git clone https://github.com/Buse86/vibe_project
cd src

python -m venv venv
source venv/bin/activate        # Linux/macOS
# venv\Scripts\activate         # Windows

pip install -r requirements.txt
```

> ⚠️ При первом запуске модель (~2.5 ГБ) будет автоматически скачана в кэш Hugging Face.

---

## ▶️ Использование

```bash
python main.py --input файл.txt --compression 30 --language auto
```

### Аргументы:
- `--input / -i` — путь к `.txt` или `.pdf` файлу (**обязательно**)
- `--compression / -c` — уровень сжатия: `20`, `30` или `50` (по умолчанию: `30`)
- `--language / -l` — язык: `en`, `ru`, `de` или `auto` (по умолчанию: `auto`)
- `--output / -o` — файл для сохранения результата (опционально)

### Примеры:

```bash
# Резюмировать русский текст с сильным сжатием
python main.py -i test_ru.txt -c 20

# Сохранить результат на немецком
python main.py -i skript_de.pdf -l de -c 50 -o zusammenfassung.txt
```

## 💡 Пример работы

**Входной текст (`test_ru.txt`):**  
> Искусственный интеллект (ИИ) — это область компьютерных наук, направленная на создание систем, способных выполнять задачи, которые обычно требуют человеческого интеллекта. К таким задачам относятся обучение, логическое рассуждение, решение проблем, восприятие и понимание языка. В последние годы ИИ добился значительного прогресса, особенно в таких направлениях, как обработка естественного языка, компьютерное зрение и робототехника.

**Команда:**
```bash
python main.py -i test_ru.txt -c 30
```

**Вывод:**
```
Искусственный интеллект — это область информатики, создающая системы, способные выполнять задачи, требующие человеческого интеллекта, такие как обучение, рассуждение и понимание языка. Несмотря на свой потенциал, ИИ вызывает этические вопросы, связанные с приватностью и предвзятостью.
```

> ✅ Результат — **абстрактивное** (не копирует дословно) и на том же языке, что и оригинал.
